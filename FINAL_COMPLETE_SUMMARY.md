## 🎓 Usage Examples

### Example 1: Create Course with Import
```

2. Clicks "Import Content" in header
3. Selects "Complete Course"
4. Uploads complete-course-example.json
5. Course created with all modules instantly
```

### Example 2: Add MCQs to Module
```
1. Admin creates/edits course
2. Expands a module

6. 15 MCQs added instantly
```

```

```
